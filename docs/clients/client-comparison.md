# Clash Verge Rev、v2rayN、v2rayNG与小火箭有什么区别？

<!-- 机场百科｜文章08｜V1.0 最新审核稿｜首次完整正文，未发布｜2026-11-20 -->

Clash Verge Rev、v2rayN、v2rayNG 和小火箭（Shadowrocket）常被放在同一个客户端推荐列表中。它们的系统定位、软件结构与功能范围并不相同，不能只凭界面或名称判断哪款更适合自己。本文的代理客户端对比以官方项目资料为依据，不展开安装与连接操作，也不评选最佳客户端。

## 代理客户端是什么？

代理客户端是运行在设备上、为网络通信提供相应处理功能的软件。软件可能具备配置管理、规则表达或其他网络相关功能，但通常不等于商业网络服务本身。设备运行的系统、软件采用的内核与配置格式共同影响功能范围。

软件可以展示连接配置，不代表所有配置都能被完全支持。理解软件与远端服务的区别，是判断是否需要另外购买服务及如何核对兼容性的基础。详见[机场节点百科](../nodes/airport-nodes.md)。

## Clash Verge Rev的软件定位

Clash Verge Rev 项目面向 Windows、macOS 和 Linux 桌面系统，使用图形界面提供网络相关功能。官方项目资料可以帮助用户确认其支持系统、维护状态和与 Mihomo 相关的特点。

它的定位是桌面客户端，而不是同名商业订阅服务。对于使用电脑的读者，除了关注系统名称，还需要查阅实际版本对应的处理器架构和系统要求。配置的兼容性应与内核能力分别核对，不能只凭界面名称判断。相关内容见[Clash机场兼容性指南](clash-airport.md)。

## v2rayN的软件定位

v2rayN 是一个图形界面客户端，项目官方介绍显示其支持 Windows、Linux 和 macOS，并支持 Xray、sing-box 等内核。历史文章有时把它简单描述为 Windows 软件，这不足以代表当前项目的支持范围。

由于内核选择及版本可能存在差异，软件的某项功能也可能有特定实现条件。读者应区分软件版本与内核版本，核对所需要的功能，而不是认为一个界面必然带有全部通信能力。

## v2rayNG的软件定位

v2rayNG 面向 Android 系统，官方项目介绍涉及 Xray 与 v2fly 相关内核支持。它不是 v2rayN 桌面安装包的手机版文件，两者属于不同项目及平台环境。

Android 不同设备与系统版本的权限管理方式可能存在差别，软件在设备端的实际行为需要结合官方说明理解。软件能安装并不代表具备所有其他平台的功能，也不代表已经验证了特定订阅的兼容性。

## Shadowrocket的软件定位

Shadowrocket 在中文语境中常被称为小火箭，App Store 页面将其描述为基于规则的代理工具。官方商店页面列出支持的 Apple 设备及相应系统要求，不同地区的商店可获得性、价格与展示内容可能变化。

它属于单独的软件产品，不能把购买客户端和购买远端网络服务混为一谈。商店上架也不表示商店平台对第三方服务质量或隐私处理进行了全面担保。本文仅引用软件介绍及系统支持，不使用商店评分作为性能证明。

## 不同设备应该关注哪些兼容性条件？

电脑用户需要确认系统版本、处理器架构和软件维护情况；手机和平板用户则要关注系统权限、官方获取途径、背景运行规则和应用商店的支持信息。家庭内多设备使用时，还需分别核对服务商对账户及同时使用设备的规定。

建议将问题分成三列：设备是否满足软件要求、软件是否支持需要的资料结构、网络服务是否对该平台提供明确说明。任一列的答案不清楚，都不宜把服务写成已经全面兼容。有关协议概念详见[代理协议区别](../nodes/proxy-protocols.md)，首次选购流程见[新手选购指南](../guides/tizi-guide.md)。

价格也应分开计算。某些开源软件的获取费用可能为零，但网络服务并不会因此免费；收费客户端的价格也不必包含服务订阅。比较长期成本时，应纳入实际需要支付的独立费用，而不是只比较软件本身。

## 如何识别官方软件来源？

首先确认项目维护者或应用开发者身份，比较公开项目介绍与发布页面是否一致。名称相似、使用同一图标或者声称拥有更高版本号，都不能证明是官方软件。来源不明的重新打包版本可能具有不同的行为。

检查发布说明、支持系统、公开安全信息以及是否要求不必要的敏感权限。即使软件来自官方来源，也仍需根据自己的安全要求判断其适用性。对于工作设备和受管设备，应遵守组织的软件安装与网络安全规范。关于私人配置和不明软件风险，阅读[机场避坑指南](../faq/airport-risks.md)。
